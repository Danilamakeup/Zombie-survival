# Topdown Zombie Survival — Multiplayer

## Что есть

- **Одиночная** — локальные зомби
- **Мультиплеер Team / FFA** — только живые игроки, **без ботов**, ники над головами
- **Закрытый бой** — локально против ботов (+ зомби)
- Регистрация ника → ник виден в игре и в табло

## Структура

```
package.json
server.js          ← Node + Socket.io
public/index.html  ← клиент (игра + меню)
```

## Локальный запуск

```bash
cd папка-с-проектом
npm install
npm start
```

Открой http://localhost:3000

## Деплой на Render

1. Залей эту папку на GitHub
2. Render → **New → Web Service**
3. Подключи репозиторий
4. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Create Web Service

После деплоя все игроки заходят по одной ссылке Render.  
Team/FFA — реальный онлайн. Закрытый бой — у каждого локально с ботами.

## Режимы

| Режим | Где | Боты | Зомби |
|-------|-----|------|-------|
| Одиночная | локально | нет | да |
| Team (5 мин) | сервер | **нет** | нет |
| FFA (10 мин) | сервер | **нет** | нет |
| Закрытый бой | локально | **да** | да |
